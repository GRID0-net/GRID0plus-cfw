# GRID0-cfw

the switch side of GRID0. sysmodule + toolbox app, one repo.

- `sys-grid0/` — ZeroTier ported to the switch as a sysmodule. lan-play over the internet, no pc needed. (from redluigi323/sys-GRID0)
- `toolbox/` — the GRID0+ toolbox homebrew app. flips the console between GRID0+ and normal online.

each side builds on its own in CI — touch one folder and only that workflow runs.
